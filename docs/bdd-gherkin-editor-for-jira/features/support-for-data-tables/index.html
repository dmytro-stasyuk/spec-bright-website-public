Support for data tables

Automatic column alignment​

Columns of tabular parameters are automatically aligned as you type.

Better looking tables​

View data tables with borders to make them more appealing and easier to work with, while the file remains just a plain text feature file.

Move rows and columns with one click​

Use toolbar buttons to easily move columns left and right or rows up and down with one click. Copy, cut and paste rows and columns easily.
