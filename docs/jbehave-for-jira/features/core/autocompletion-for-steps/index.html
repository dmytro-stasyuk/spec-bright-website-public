Autocompletion for steps

Story editor panel has built-in auto completion support for existing steps so you will never need to remember, guess or refer to your source code to find out what steps exactly are available that you can use for your new story or scenario. To use it simply begin a new line with a step keyword (Given/When/Then) followed by space and then hit Ctr+Space on your keyboard to bring up the drop down menu that shows you all available steps that you can use by simply clicking on it with your mouse or using arrow keys on the keyboard to select the required step followed by Enter add it inline. 

Suggested steps are filtered as you type, so after you enter some text the list of suggested steps will be filtered to show only those entries that match your input using a fuzzy search algorithm.
