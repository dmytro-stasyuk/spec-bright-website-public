How-to install (Jira Data Center)

This page describes how to install the BDD for Jira app and enable it for a particular project.

  1. Navigate to the “Add-ons” → “Find new add-ons” page and type in “BDD for Jira“ in the search field

  2. Follow standard Jira app installer steps to complete the installation

  3. Once the app is installed it can then be enabled for specific Jira projects. To do this navigate to the Project administration area and select the project for which you’d like to enable the app. Then from the left side menu links click on the “BDD for Jira” link

    ![Screenshot 2024-08-30 at 18.26.59.png](<./img/how-to-install-jira-data-center/Screenshot 2024-08-30 at 18.26.59.png>)

  4. Then on the loaded page, move the selector to Enabled and click Save.

    ![Screenshot 2024-08-30 at 18.29.21.png](<./img/how-to-install-jira-data-center/Screenshot 2024-08-30 at 18.29.21.png>)

  5. Then once you are on the view issue page click on the 'Add Feature' from the More toolbar actions menu.

  6. The page reloads and a new panel titled Feature will be added by the app where you can work with the feature file associated with that particular Jira issue.
